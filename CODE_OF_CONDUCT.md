# Code of Conduct

This project welcomes contributors who help make the driver safer, more reliable, and easier to use. Everyone participating in project spaces is expected to treat others with respect and act in good faith.

Examples of behavior that supports a healthy community include clear and respectful discussion, constructive feedback, acknowledging mistakes, and focusing criticism on ideas and code.

Harassment, personal attacks, intimidation, discriminatory language, deliberate disruption, and publishing another person's private information are not acceptable.

The repository owner is responsible for interpreting and enforcing this code. Report conduct concerns privately through the contact options on the repository owner's GitHub profile (`@iewil`). The owner will review reports and may remove comments, restrict participation, or take other action appropriate to the situation. Do not post biometric data, raw USB captures, or personal information in a public issue.
